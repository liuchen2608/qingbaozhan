# 情报站 MVP 需求基线

个人 AI 行业情报与知识管理系统，服务于从 AIGC 产品交付向产品经理成长。质量优先、保留出处、区分事实与推断，不编造缺失信息。

## 本版闭环

维护信息源 → 手动录入或导入链接与正文 → AI 摘要、唯一主要分类和多标签 → 五维评分与产品经理分析 → 检索、收藏、笔记 → 日报／周报与导出。

第一版覆盖用户提出的七项验收：维护来源、添加或导入推文链接、模型摘要分类、产品经理分析、评分排序、历史检索、日报。真实模型效果需要用户自己的密钥验证。

## 领域规则

主要分类：大模型技术、AI Agent、AI Native 产品、AIGC 图像生成、AIGC 视频生成、AI 音频生成、AI 产品发布、AI 商业化、AI 行业融资与市场趋势。

技术创新价值25、产品应用价值25、商业化潜力25、行业影响力15、个人目标关联10；服务器计算总分。80–100重点研究、60–79值得关注、40–59普通信息、0–39低优先级。每维必须包含理由，评分不代表投资判断。

分析涵盖摘要、技术／产品变化、问题、场景、用户价值、商业价值、产品经理启发、证据状态、待验证信息，以及用户规定的产品经理八问。

日报按北京时间及原文发布时间选取当前分析有效、评分≥60的最多10条，不足5条不补齐。周报为截至选定日期7天的分析整理，不声称进行了额外联网趋势核实。

## 不在本版范围

X 自动发现、自动采集正文、定时采集、飞书推送同步、多源自动化、智能问答。未验证 X 接口价格、权限和限额，不假设免费可用，不使用绕过平台限制的爬虫。

实际来源 Excel 尚未提供。用户列举的机构与人名是候选来源，不擅自猜测账号主页；以用户清单为准。

## 后续阶段

1. 使用真实密钥验收分析质量；取得实际来源清单。
2. 核实官方 X API 或合法授权提供商的套餐、访问权限、限流与成本，再实现采集适配器。
3. 逐步增加调度、飞书、多来源与趋势能力。
